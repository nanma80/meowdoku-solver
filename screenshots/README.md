# Screenshot fixtures

Names follow `device-grid-puzzle-state.png`:

- `device`: `iphone` or `ipad`.
- `grid`: zero-padded dimensions, such as `08x08` or `12x12`.
- `puzzle`: `level-NNN`, `daily-MMDD`, or `board-01` when no level is visible.
- `state`: `clean`, `partial` (cats and/or Xs), or `celebration`.

The three `iphone-08x08-board-01-*` files show the same puzzle at different stages. Celebration screenshots are reference material, not supported input fixtures.
